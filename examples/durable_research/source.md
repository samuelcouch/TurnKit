# Research dossier: durable report generation

Source: local:durable-report-requirements

The product must accept report requests without keeping the submitter running.
Two independent reviewers must assess the same research before publication.
Reports must remain readable after a process restart. Follow-up messages must
not alter the input snapshot of work already executing. If a worker dies after
a report is saved, recovery must not publish that completed report a second time.

This is a fixed, fictional product brief, not external factual research.
